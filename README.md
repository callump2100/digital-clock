Digital Clock
A simple digital clock that updates every second using JavaScript.

Features
12‑hour format

AM/PM indicator

Updates every second

Clean and responsive layout

Lightweight and beginner‑friendly codebase

How It Works
The clock uses JavaScript’s Date object to get the current time and updates the display every second using setInterval().

File Structure
index.html — structure of the clock

style.css — styling and layout

index.js — time logic and DOM updates
